КАК ЗАПУСТИТЬ
=============

1. Распакуйте этот архив в пустую папку.
   Должно получиться:
       SPEC.md
       START.txt
       public/agent/...
       public/og-default.jpg

2. Откройте SPEC.md и заполните плейсхолдеры {{...}} в разделе 2.
   Их 8: фамилия, стаж, объём сделок, telegram, email, домен, юрлицо.
   Имя, телефон, WhatsApp и Instagram уже подставлены.

3. Откройте эту папку в Claude Code и дайте команду:

   Прочитай SPEC.md целиком. Это техзадание на сайт. Папка public/ уже
   содержит готовые изображения — используй их, не создавай заново.
   Реализуй по этапам, начиная с «Этап 0». После каждого этапа
   останавливайся, показывай что сделано и жди подтверждения.
   Не выдумывай функционал, которого нет в SPEC.md.

   Если нужно всё за один проход — замените последние две фразы на:
   «Реализуй этапы 0-5 подряд, без остановок, в конце запусти сборку
   и покажи результат».

4. Claude Code сам поставит зависимости и поднимет проект вокруг
   существующей папки public/. Ничего предварительно ставить не нужно,
   кроме Node.js.

ЧТО ПОНАДОБИТСЯ ПО ХОДУ
=======================
- Строка подключения к PostgreSQL (проще всего Neon, бесплатный тариф)
- Токен Telegram-бота и chat_id для уведомлений о заявках (необязательно)
- Токен Vercel Blob для загрузки фото в админке

Без них проект соберётся и запустится, но заявки будут только писаться
в базу, а загрузка фото не заработает. Все необязательные интеграции
отключаются сами, если переменных нет.
